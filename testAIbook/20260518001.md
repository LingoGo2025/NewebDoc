## 錯誤代碼

> 以下錯誤代碼均於 **HTTP 200** 回應中回傳，錯誤訊息包含於 response body。

| 代碼 | 說明 |
|------|------|
| TRA10001 | 商店資料取得失敗，商店代號錯誤 |
| TRA10003 | 金額格式錯誤，金額必須為數字且數字需大於0。此筆交易超過商店單筆金額限制，請與商店連繫 |
| TRA10008 | 資料加解密錯誤 |
| TRA10009 | 商店代號不可空白 |
| TRA10012 | 商店代號停用 |

## 簡介與交易流程

藍新金流為商店提供以單獨串接信用卡幕後授權支付工具，消費者於商店之網站選擇信用卡支付方式並提供信用卡卡號資料給商店，再由商店利用此 API 提供信用卡交易資料給藍新金流，經收單機構授權取得授權回覆訊息後即時回傳商店，完成訂單作業。

## 名詞定義

商店（Merchant）：使用藍新金流服務的賣方
收單機構（Acquirer）：實際處理信用卡授權的銀行
幕後授權：消費者輸入卡號於商店網站，由商店後端呼叫本 API
幕前授權：消費者於藍新金流頁面輸入卡號

## 測試資料

信用卡卡號：4000-2211-1111-1111
信用卡到期日：任意未來日期，格式為yymm
信用卡末三碼：任意三碼數字

## AES256 加密規格

### 加密演算法規格

| 項目 | 規格 |
|:-----|:-----|
| 演算法 | AES |
| 金鑰長度 | 256 bits（32 bytes） |
| 加密模式 | CBC |
| 填充方式 | PKCS#7 |
| 輸出格式 | Hex 十六進位 |
| 輸入編碼 | UTF-8 |
| Key 長度 | 32 bytes |
| IV 長度 | 16 bytes |

### 適用欄位群組

- **PostData_內含欄位**（AES加密_字串）（請求）　傳送欄位名稱：`PostData_`

### 加密範例

> 以下為固定示範數值，**請勿用於正式環境**。

| 項目 | 值 |
|:-----|:---|
| Key（ASCII，32 bytes） | `12345678901234567890123456789012` |
| IV（ASCII，16 bytes） | `1234567890123456` |
| 加密前字串（plaintext） | `{"MerchantID":"2000001","Amount":"1000","OrderID":"TEST001","Currency":"TWD"}` |
| 加密後（Hex 十六進位） | `4fbf600f84fd69e9813bccc943d247d9d0dcc9134d645ea4643c3b09604c72236c27ba833a110a6ad7af0c92167c8a8db3513353b48451bd338766dfa3b84cd8839fa86cc45e8866126e620e791aea02` |

> 驗證方法：使用上述 Key / IV 對加密後字串解密，應還原為加密前字串。

/**
 * Encrypt PostData using AES-256-CBC (PKCS7 Padding)
 */
function create_aes_encrypt($parameter = [], $key = "", $iv = "") {
    $return_str = http_build_query($parameter);
    return base64_encode(openssl_encrypt($return_str, 'aes-256-cbc', $key, OPENSSL_RAW_DATA, $iv));
}

/**
 * Create CheckCode using SHA256
 */
function create_sha256_hash($postDataValue, $key, $iv) {
    $sha_string = "HashKey=" . $key . "&" . $postDataValue . "&HashIV=" . $iv;
    return strtoupper(hash("sha256", $sha_string));
}

// --- Prepare PostData_ (AES Encrypted Fields) ---
$postDataArray = [
    'TimeStamp'       => time(),           // Required: Unix Timestamp
    'Version'         => '1.1',            // Required: Fixed 1.1

];

// 2. Generate CheckCode

// --- Prepare Request Payload ---

    'MerchantID_ ' => $merchantId,

    'Content-Type: application/x-www-form-urlencoded'
]);

$httpCode = curl_getinfo($ch, CURLINFO_HTTP_CODE);
$curlError = curl_error($ch);

// curl_close($ch); // Skipped as per requirement for PHP 8.0+ compatibility

    $errorMsg = "CURL Error: " . $curlError;
} else {
    if ($httpCode === 200) {
        $resultData = json_decode($response, true);
    } else {
        $errorMsg = "HTTP Request Failed with Status: " . $httpCode;
    }
}

/**
 * AES-256-CBC Encryption (PKCS7 Padding)
 */
function encryptAES256(data, key, iv) {
    const cipher = crypto.createCipheriv('aes-256-cbc', key, iv);
    // Node.js crypto uses PKCS7 by default
    let encrypted = cipher.update(data, 'utf8', 'base64');
    encrypted += cipher.final('base64');
    return encrypted;
}

/**
 * SHA256 Hashing
 */
function hashSHA256(data) {
    return crypto.createHash('sha256').update(data).digest('hex').toUpperCase();
}

 * Route: Process Authorization

app.post('/authorize', async (req, res) => {
    try {
        const { Amt, ProdDesc, PayerEmail, CardNo, Exp } = req.body;

        // 1. Prepare PostData_ fields
        const postDataObj = {
            TimeStamp: Math.floor(Date.now() / 1000),
            Version: CONFIG.Version,
            MerchantOrderNo: 'ORDER_' + Date.now(),
            Amt: parseInt(Amt),
            ProdDesc: ProdDesc,
            PayerEmail: PayerEmail,
            CardNo: CardNo,
            Exp: Exp,
            // Non-required fields (optional)
            Inst: 0,
            Red: 0,
            CardAE: 0
        };

        // 2. Convert object to URL query string
        const postDataString = qs.stringify(postDataObj);

        // 3. AES Encrypt the string
        const encryptedData = encryptAES256(postDataString, CONFIG.HashKey, CONFIG.HashIV);

        // 4. Create CheckCode (SHA256)
        // Order: HashKey + PostData_ + HashIV
        const checkCodeInput = `HashKey=${CONFIG.HashKey}&${encryptedData}&HashIV=${CONFIG.HashIV}`;
        const checkCode = hashSHA256(checkCodeInput);

        // 5. Prepare Payload for API (Content-Type: application/x-www-form-urlencoded)
        const requestPayload = {
            MerchantID_: CONFIG.MerchantID,
            PostData_: encryptedData,
            CheckCode: checkCode,
            Pos_: 'JSON'
        };

        // 6. Send Request to NewebPay
        const response = await axios.post(CONFIG.URL, qs.stringify(requestPayload), {
            headers: { 'Content-Type': 'application/x-www-form-urlencoded' }
        });

        // 7. Handle API Response
        const apiResult = response.data;

        if (apiResult.Status !== 'SUCCESS') {
            const errorMsg = handleErrorCode(apiResult.Status);
            return res.status(400).json({
                success: false,
                status: apiResult.Status,
                message: apiResult.Message,
                description: errorMsg,
                raw: apiResult
            });
        }

        // Return successful result to frontend
        return res.json({
            success: true,
            status: apiResult.Status,
            message: apiResult.Message,
            result: apiResult.Result
        });

    } catch (error) {
        console.error('Auth Error:', error.message);
        res.status(500).json({ 
            success: false, 
            message: 'Internal Server Error', 
            error: error.message 
        });
    }
});
