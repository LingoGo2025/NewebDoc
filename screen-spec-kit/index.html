screen-spec-kit

一行指令裝好環境，一段提示詞讓 AI 建好畫面規格專案

先貼一行指令安裝所需軟體，再到 Claude Code 或 Codex 貼上提示詞。AI 會建立專案並一步一步訪談你，產出網站地圖、頁面示意圖、跨頁流程、架構圖與規格文件。

1安裝環境（只需做一次）

開始選單搜尋「PowerShell」並開啟（不需要系統管理員），貼上這一行後按 Enter：

[Net.ServicePointManager]::SecurityProtocol=3072; $w=New-Object Net.WebClient; $w.Encoding=[Text.Encoding]::UTF8; iex $w.DownloadString('setup-windows.ps1')

開啟「終端機」App（啟動台 → 其他，或用 Spotlight 搜尋），貼上這一行後按 return：

curl -fsSL setup-mac.sh | bash

腳本會下載免安裝版的 Python 與 PlantUML，以及工具組，全部放在家目錄的 NewebDoc 資料夾，不需要系統管理員權限或密碼。約需下載 100MB，看到最後一行「完成！」就好了。之後要更新工具組，再執行同一行即可。

想先看腳本內容：setup-windows.ps1、setup-mac.sh。

2準備 AI 工具

兩種擇一，安裝並登入即可（桌面 App 或終端機版都可以）。裝好第 1 步後請重新開啟 AI 工具。

  • 安裝：Claude Code 官方頁面，桌面 App 與終端機版都可以。
  • 開啟方式：桌面 App 選擇資料夾後開新對話；終端機版在資料夾內執行 claude。
  • 過程中 Claude 會詢問是否允許讀取網址、執行指令，請選擇允許。
  • 安裝：Codex 官方頁面，App 與終端機版（CLI）都可以。
  • 開啟方式：App 選擇資料夾後開新工作；終端機版在資料夾內執行 codex。
  • Codex 預設會限制網路與資料夾外的存取；讀取網址、執行工具組時會詢問權限，請選擇允許。

3開空資料夾，貼上提示詞

先建立一個新資料夾，用來放這次的專案（例如桌面上的「活動報名平台」），在這個資料夾開啟 AI 工具，貼上：

請幫我導入 screen-spec-kit 並建立新專案：先讀取 SETUP.md（可以用 curl 下載來讀），再照裡面的步驟一步一步做。

接下來 AI 會依序完成：

  1. 確認環境檢查第 1 步是否裝好；缺少時會請你執行第 1 步那一行（AI 不會自己安裝軟體）。
  2. 建立專案問你專案名稱、存放位置，以及用幾句話描述這個系統（例如「電子發票加值服務平台」）。
  3. 快速起稿再問你最多 4 題選擇題，就依產業常識一次產生整案初稿：網站地圖、每頁示意圖、跨頁流程、架構圖與規格骨架。AI 推測的內容都標「AI 起稿」，法規、金流、API 欄位只列待確認。
  4. 逐區審閱打開 index.html 看初稿，AI 一區一區請你決定保留、修改或刪除，確認後再補每頁細節。需求已經很清楚時，也可以改成一題一題訪談。

中途關掉也沒關係：在同一個資料夾重新開啟 AI，貼上同一段提示詞，AI 會從沒完成的地方繼續。

之後常用的說法

以下都在專案資料夾開啟 AI 後使用。

接續訪談

先跑 interview_status.py 看訪談進度，從下一個未完成的階段繼續。

修改內容

我要修改這個專案：〈寫下想改的內容，例如在會員中心新增一頁〉。先依規範查影響範圍給我確認，再動手。

更新工具組並升級專案

請依 SETUP.md 的「升級既有專案」：更新工具組，再升級這個專案，正式升級前先告訴我會變更哪些檔案。

常見問題

Claude Code 和 Codex 做出來的結果一樣嗎？

一樣。設計規範是專案裡的一般文件（規範/），不綁定 AI；同一個專案也可以中途換另一套 AI 接續。

我的資料會被上傳到哪裡？

工具組、規格與圖檔都在你的電腦上，流程圖與架構圖用本機 PlantUML 產生，不經過線上服務。對話內容則依你使用的 AI 服務處理。

中途斷掉或關掉了怎麼辦？

在同一個資料夾重新開啟 AI，貼上同一段提示詞（或「接續訪談」那段）。進度都記錄在專案檔案裡，AI 會從沒完成的地方繼續。

安裝腳本會動到我電腦的哪些地方？

只有家目錄的 NewebDoc 資料夾（工具組與 env 裡的免安裝軟體），另外把 NewebDoc/env 加進 PATH：Windows 寫在使用者環境變數（並設定 PYTHONUTF8=1），macOS 在 ~/.zshrc 加一行。不想用了，刪掉 NewebDoc 資料夾與這些設定即可。

為什麼不讓 AI 自己安裝軟體？

AI 工具（特別是 Codex）在沙盒裡執行指令，常常無法執行安裝程式；有些電腦也沒有 winget 或 Homebrew。安裝腳本由你自己執行、只用免安裝版，結果每台電腦都一樣。

做好的成果怎麼看？

雙擊專案資料夾裡的 index.html，用瀏覽器開啟即可，不需要伺服器。裡面有網站地圖、可點擊放大的示意圖、流程與文件完整度。
