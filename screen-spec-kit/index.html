screen-spec-kit

一段提示詞，讓 AI 幫你建好畫面規格專案

在 Claude Code 或 Codex 貼上下方提示詞，AI 會自動下載工具組、檢查並安裝所需軟體，接著一步一步訪談你，產出網站地圖、頁面示意圖、跨頁流程、架構圖與規格文件。

1準備 AI 工具

兩種擇一，安裝並登入即可（桌面 App 或終端機版都可以）。

  • 安裝：Claude Code 官方頁面，桌面 App 與終端機版都可以。
  • 開啟方式：桌面 App 選擇資料夾後開新對話；終端機版在資料夾內執行 claude。
  • 過程中 Claude 會詢問是否允許讀取網址、執行指令，請選擇允許。
  • 安裝：Codex 官方頁面，App 與終端機版（CLI）都可以。
  • 開啟方式：App 選擇資料夾後開新工作；終端機版在資料夾內執行 codex。
  • Codex 預設會限制網路與資料夾外的寫入；下載工具組、安裝軟體時會詢問權限，請選擇允許。

2開一個空資料夾

先建立一個新資料夾，用來放這次的專案（例如桌面上的「活動報名平台」），再在這個資料夾開啟 AI 工具。

3貼上提示詞

請幫我導入 screen-spec-kit 並建立新專案：先讀取 SETUP.md（可以用 curl 下載來讀），再照裡面的步驟一步一步做。

接下來 AI 會依序完成：

  1. 下載工具組只下載 PMSkill 資料夾，放到家目錄的 NewebDoc/PMSkill，所有專案共用；已下載過就只更新。
  2. 檢查軟體確認 Python、Git、PlantUML（含 Java、Graphviz）；缺少的會說明後安裝。macOS 用 Homebrew，Windows 用 winget。
  3. 建立專案問你專案名稱與存放位置，建立空白專案（規格、網站地圖、首頁、架構圖骨架）。
  4. 開始訪談依 12 個階段提問：系統定位、角色、業務規則、頁面、流程、外部串接……每完成一段就寫入規格與示意圖。

需要密碼的步驟請自己來：macOS 第一次安裝 Homebrew 時需要輸入電腦密碼，AI 不會代輸，它會把指令給你，請貼到「終端機」App 執行。Windows 安裝軟體後可能要重開 AI 工具；重開後在同一個資料夾貼上同一段提示詞，AI 會從沒完成的地方繼續。

4之後常用的說法

以下都在專案資料夾開啟 AI 後使用。

接續訪談

先跑 interview_status.py 看訪談進度，從下一個未完成的階段繼續。

修改內容

我要修改這個專案：〈寫下想改的內容，例如在會員中心新增一頁〉。先依規範查影響範圍給我確認，再動手。

更新工具組並升級專案

請依 SETUP.md 的「升級既有專案」：更新工具組，再升級這個專案，正式升級前先告訴我會變更哪些檔案。

常見問題

Claude Code 和 Codex 做出來的結果一樣嗎？

一樣。設計規範是專案裡的一般文件（規範/），不綁定 AI；同一個專案也可以中途換另一套 AI 接續。

我的資料會被上傳到哪裡？

工具組、規格與圖檔都在你的電腦上，流程圖與架構圖用本機 PlantUML 產生，不經過線上服務。對話內容則依你使用的 AI 服務處理。

中途斷掉或關掉了怎麼辦？

在同一個資料夾重新開啟 AI，貼上同一段提示詞（或「接續訪談」那段）。進度都記錄在專案檔案裡，AI 會從沒完成的地方繼續。

Windows 可以用嗎？

可以。AI 會用 winget 安裝 Git、Python、Java、Graphviz，並下載官方 PlantUML；部分設定要重開 AI 工具後才生效。

做好的成果怎麼看？

雙擊專案資料夾裡的 index.html，用瀏覽器開啟即可，不需要伺服器。裡面有網站地圖、可點擊放大的示意圖、流程與文件完整度。
