screen-spec-kit

一行指令裝好環境，一段提示詞讓 AI 建好畫面規格專案

描述你的系統主題，AI 最多問 10 題，通常十幾分鐘內就產出第一版完整規格：網站地圖、每頁示意圖、跨頁流程、架構圖與規格文件。想每一步都確認，也可以選階段式。

1安裝環境（只需做一次）

開始選單搜尋「PowerShell」並開啟（一般開啟即可，不需要「以系統管理員身分執行」），貼上這一行後按 Enter：

[Net.ServicePointManager]::SecurityProtocol=3072; $w=New-Object Net.WebClient; $w.Encoding=[Text.Encoding]::UTF8; iex $w.DownloadString('setup-windows.ps1')

開啟「終端機」App（用 Spotlight 搜尋「終端機」），貼上這一行後按 return：

curl -fsSL setup-mac.sh | bash

腳本會下載免安裝版的 Python 與 PlantUML，以及工具組，全部放在家目錄的 NewebDoc 資料夾。不需要系統管理員權限或密碼，也不跑安裝程式。約需下載 100MB，視網路速度約需幾分鐘。

成功的樣子

最後幾行像這樣（版本與路徑依電腦而不同），看到「環境：全部就緒」與「完成！」就好了：

OK ｜Python 3.9 以上：3.12.16 OK ｜PlantUML（本機渲染）：1.2026.10 OK ｜screen-spec-kit 工具組：…（…\NewebDoc\screen-spec-kit） 環境：全部就緒 完成！下一步：重新開啟 AI 工具（Claude Code 或 Codex），在一個空資料夾貼上入門頁第 3 步的提示詞。

出現「缺少」或「錯誤」時：把整段訊息複製起來，貼給 AI 工具或維護者協助判斷；修正後可以重新執行同一行，已完成的部分會自動略過。若錯誤寫「可能被公司防毒或應用程式控制擋下」，請 MIS 放行家目錄的 NewebDoc\env 資料夾。

之後要更新工具組，再執行同一行即可。想先看腳本內容：setup-windows.ps1、setup-mac.sh。

2準備 AI 工具

兩種擇一，安裝並登入即可（桌面 App 或終端機版都可以）。裝好第 1 步後請重新開啟 AI 工具。

  • 安裝：Claude Code 官方頁面，桌面 App 與終端機版都可以。
  • 開啟方式：桌面 App 選擇資料夾後開新對話；終端機版在資料夾內執行 claude。
  • 過程中 Claude 會詢問是否允許讀取網址、執行指令，請選擇允許。
  • 安裝：Codex 官方頁面，App 與終端機版（CLI）都可以。
  • 開啟方式：App 選擇資料夾後開新工作；終端機版在資料夾內執行 codex。
  • Codex 預設會限制網路與資料夾外的存取；讀取網址、執行工具組時會詢問權限，請選擇允許。

3開空資料夾，貼上提示詞

先建立一個新資料夾，用來放這次的專案（例如桌面上的「活動報名平台」），在這個資料夾開啟 AI 工具，貼上：

請幫我導入 screen-spec-kit 並建立新專案：先讀取 SETUP.md（可以用 curl 下載來讀），再照裡面的步驟一步一步做。

AI 會先確認環境（缺少時請你執行第 1 步那一行，AI 不會自己安裝軟體），再問你專案名稱、存放位置，以及用幾句話描述這個系統。接著請你選模式：

之後常用的說法

以下都在專案資料夾開啟 AI 後使用。

審閱全自動的初稿

請依 規範/新專案.md 的「審閱起稿」，從第一個待審閱的階段開始，把初稿整理成表格給我確認。

接續上次的進度

先跑 interview_status.py 看進度，從下一個待審閱或未完成的階段繼續。

修改內容

我要修改這個專案：〈寫下想改的內容，例如在會員中心新增一頁〉。先依規範查影響範圍給我確認，再動手。

更新工具組並升級專案

請依 SETUP.md 的「升級既有專案」：更新工具組，再升級這個專案，正式升級前先告訴我會變更哪些檔案。

常見問題

公司電腦可以用嗎？需要找 MIS 嗎？

安裝腳本不需要系統管理員權限、不跑安裝程式，只把免安裝版軟體解壓縮到家目錄的 NewebDoc 資料夾，一般不需要 MIS 處理。少數公司的防毒或應用程式管控會擋下下載的執行檔，這時請 MIS 放行 NewebDoc\env 資料夾。

AI 工具本身怎麼裝？

依官方頁面安裝 Claude Code 或 Codex。有些版本或桌面 App 會用安裝程式，公司電腦可能要請 MIS 協助，這一步跟本工具組無關；已經有其中一種就不用再裝。

全自動要多久？

回答問題約 5 分鐘；AI 整理起稿內容需要幾分鐘（依模型速度），產生所有檔案只要幾秒。通常十幾分鐘內就能打開 index.html 看第一版。

AI 起稿的內容可以相信嗎？

它是依產業常識推測的第一版，方便你挑錯，不是定案。所有推測的地方都標「AI 起稿・待審閱」，示意圖上也有提醒框；法規、金流、API 欄位、費率與期限一律只列「待確認」，不寫具體數字或條文。審閱確認過的部分才會拿掉標記。

Claude Code 和 Codex 做出來的結果一樣嗎？

結構一樣：檔案都是由工具依同一份規範產生，設計規範是專案裡的一般文件（規範/），不綁定 AI；同一個專案也可以中途換另一套 AI 接續。內容細節會依模型的判斷略有不同。

我的資料會被上傳到哪裡？

工具組、規格與圖檔都在你的電腦上，流程圖與架構圖用本機 PlantUML 產生，不經過線上服務。對話內容則依你使用的 AI 服務處理。

安裝腳本會動到我電腦的哪些地方？

只有家目錄的 NewebDoc 資料夾（工具組與 env 裡的免安裝軟體），另外把 NewebDoc/env 加進 PATH：Windows 寫在使用者環境變數（並設定 PYTHONUTF8=1），macOS 在 ~/.zshrc 加一行。不想用了，刪掉 NewebDoc 資料夾與這些設定即可。

為什麼不讓 AI 自己安裝軟體？

AI 工具（特別是 Codex）在沙盒裡執行指令，常常無法執行安裝程式；有些電腦也沒有 winget 或 Homebrew。安裝腳本由你自己執行、只用免安裝版，結果每台電腦都一樣。

做好的成果怎麼看？

雙擊專案資料夾裡的 index.html，用瀏覽器開啟即可，不需要伺服器。裡面有網站地圖、可點擊放大的示意圖、流程與文件完整度，可以先看上面的範例。
